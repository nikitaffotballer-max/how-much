# Хау мач

Сервис, который собирает электронные чеки с почты, раскладывает покупки по товарам и показывает, на что на самом деле уходят деньги и как дорожает ваша личная корзина.

Статус: проектирование. Техническое задание — [docs/TZ.md](docs/TZ.md), макеты — [docs/design](docs/design).

Стек: React, TypeScript, Node.js (Fastify), PostgreSQL, Redis + BullMQ, LLM через Ollama/GigaChat, оплата ЮKassa.
