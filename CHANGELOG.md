# Changelog

Все заметные изменения проекта. Версии — по [SemVer](https://semver.org/lang/ru/): вторая цифра — новые возможности, третья — исправления.

## v0.4.0 — 2026-10-13

- Экраны входа и регистрации в стиле Material 3: проверка полей, показ пароля, согласие на обработку данных.
- Кнопка «Посмотреть демо без регистрации» и демо-аккаунт с покупками за два месяца (`pnpm db:seed:demo`).
- Дашборд закрыт входом и считает сводку из настоящих чеков: текущий месяц против тех же дней прошлого, категории по товарам, траты по дням по московскому времени.
- Пустое состояние дашборда для нового пользователя, меню профиля с выходом, плашка пробного периода с числом оставшихся дней.
- Убраны элементы-заглушки, которые ничего не делали: поиск, колокольчик, переключатель периода.

## v0.3.0 — 2026-10-13

- База данных PostgreSQL на Prisma 7: схема из ТЗ, первая миграция, справочник из 18 категорий.
- API: регистрация, вход, выход и профиль (`/auth/*`, `/me`). Пароли — argon2id, сессия — в httpOnly-cookie, в базе только хеш токена. Ограничение 10 попыток входа в минуту.
- Новый пользователь получает 14 дней Pro бесплатно.
- Единый формат ошибок API `{ code, message }`.
- CI запускает тесты на настоящей базе PostgreSQL.

## v0.2.1 — 2026-10-13

- CI: исправлена установка зависимостей на Linux.

## v0.2.0 — 2026-10-13

- Линтер, форматирование, CI в GitHub Actions.
